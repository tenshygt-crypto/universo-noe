Crea y publica una página web llamada "Universo Noé" usando HTML, CSS y JavaScript.

La página debe tener un diseño romántico, mágico y espacial inspirado en un pequeño universo de cuento.

CARACTERÍSTICAS:

1. Crear una pantalla principal con el título "Universo Noé".
2. Agregar un fondo de universo con estrellas, planetas, nebulosas y flores.
3. Crear una sección donde las estrellas formen visualmente la palabra "NOÉ".
4. Cada estrella debe ser interactiva: al tocarla debe aparecer un mensaje bonito diferente.
5. Agregar muchas flores alrededor del universo.
6. Las flores también deben ser interactivas y mostrar mensajes.
7. Agregar una rosa en el centro.
8. Al tocar la rosa, debe florecer, aumentar de tamaño y emitir un brillo.
9. Agregar un pequeño planeta inspirado en el mundo de El Principito.
10. Agregar un pequeño viajero, un zorro y varios planetas interactivos.
11. Al tocar cada planeta, debe realizar una pequeña animación de viaje y mostrar un mensaje.
12. Crear partículas y pequeñas estrellas que sigan el movimiento del dedo en celulares o del mouse en computadora.
13. Agregar estrellas fugaces animadas.
14. Crear transiciones suaves y efectos de brillo.
15. Hacer que todo sea responsive y funcione correctamente en teléfonos Android y computadoras.
16. Agregar una sección donde pueda escribir mis propios mensajes y convertirlos en mensajes de las estrellas.
17. Mantener todos los elementos dentro de una sola página.
18. No utilizar archivos externos obligatorios: todo el código debe estar dentro de index.html.
19. El resultado debe ser visualmente elegante, romántico, mágico y de alta calidad.
20. La página debe funcionar directamente en GitHub Pages.

El archivo principal debe llamarse:

index.html

La página debe quedar lista para publicarse desde la rama main y la carpeta raíz.
